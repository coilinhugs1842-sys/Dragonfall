# Dragonfall

A browser dragon-riding team battler, **1v1 up to 5v5**. One player hosts in their browser, and friends join with
a room code. Built with three.js and tuned for laptops with Intel integrated graphics.

> **Status: planning and setup done, no game code yet.** Next step: Phase 0 (see `docs/ROADMAP.md`).
